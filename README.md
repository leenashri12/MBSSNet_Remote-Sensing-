# 🛰️ MBSSNet — Mamba-Based Joint Semantic Segmentation for Optical & SAR Images

> A PyTorch implementation of **MBSSNet** (Li et al., IEEE LGRS 2025) for pixel-wise land cover classification using fused optical and synthetic aperture radar (SAR) satellite imagery.

---

## 🧠 What's This About?

Satellite images come in two flavors — **optical** (like Google Earth, depends on sunlight) and **SAR** (radar-based, works in clouds and darkness). Each has blind spots. This project fuses both using a novel architecture built on **Mamba's selective state-space model**, achieving global context awareness at a fraction of the cost of Transformers.

The core idea: instead of expensive O(n²) self-attention, we use **SS2D** (2D-Selective-Scan) — a 4-directional sweep that gives every pixel information about every other pixel in O(n) time.

## 🏗️ Architecture Overview

```
Optical (4ch) ──► [ResNet-34] ──┐     ┌── [VSS Decoder] ──► Segmentation Map
                                ├ CMFM ┤                     (8 classes)
SAR (1ch) ──────► [ResNet-34] ──┘     └── skip connections
```

**Three key components:**

1. **PSNet (Dual-Branch Encoder)** — Two modified ResNet-34 networks independently extract multi-scale features from optical and SAR inputs. The first conv layer uses stride=1 (instead of 2) to preserve spatial resolution.

2. **CMFM (Cross-Modal Fusion Module)** — Applied at all 4 encoder scales. Uses Channel Exchange (parameter-free information swap) → SFFM (parallel VSS blocks with SS2D) → DFFM (linear projection) to fuse features without losing modality-specific information.

3. **VSS Decoder** — 4-stage progressive upsampling with skip connections. Each stage contains a VSS block that captures cross-scale contextual information using SS2D scanning.

## 🚀 Quick Start

### 1. Preprocessing

```bash
python preprocess_data.py
# Output: 29,400 aligned patches split into train/val/test
```

### 2. CPU Demo (No GPU Required)

```bash
python test_demo.py
# Trains a 1.1M-param mini-MBSSNet on 100 real patches
# Completes in ~10 minutes, proves the full pipeline works
```

### 3. Full GPU Training

```bash
# Install dependencies
pip install torch torchvision opencv-python numpy einops mamba-ssm

# Train (30 epochs, paper settings)
python train.py --batch_size 4 --num_workers 4 --epochs 30

# Resume if interrupted
python train.py --resume checkpoints/latest_checkpoint.pth
```

### 4. Visualization

```bash
python visualize.py --num_samples 10 --split test
# Generates side-by-side [SAR] [Optical] [Ground Truth] [Prediction] images
```

## 🔬 The SS2D Core — How It Works

Traditional self-attention computes pairwise relationships between all pixels — O(n²) for n pixels. For a 256×256 image, that's 4.3 billion operations per layer.

**SS2D** takes a different approach:

1. **Scan Expand** — Unfold the 2D feature map into 4 sequences (left→right, right→left, top→bottom, bottom→top)
2. **S6 Selective Scan** — Process each sequence with Mamba's input-dependent state-space model
3. **Scan Merge** — Sum and reshape back to 2D

Each pixel ends up with information from every other pixel, but the cost is only O(n). That's what makes this practical for high-resolution satellite imagery.
